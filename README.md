# مكتبي الإلكتروني — نظام إدارة مكتب المحاماة

نظام ويب بملف واحد (`index.html`) لإدارة مكتب المحاماة: القضايا، الموكلون، الجلسات، المهام، التوكيلات، والنسخ الاحتياطي. واجهة عربية (RTL) تعمل بدون خادم.

## التشغيل
- افتح الرابط بعد النشر على GitHub Pages، أو افتح `index.html` مباشرة في المتصفح.
- البيانات تُحفظ محليًا في متصفح المستخدم، ولا تُرفع إلى GitHub.

## النشر على GitHub Pages
1. Settings ← Pages
2. Source: Deploy from a branch
3. Branch: `main` / مجلد `/ (root)` ← Save
4. الرابط: `https://USERNAME.github.io/REPO-NAME/`

## تنبيه خصوصية
لا ترفع إلى المستودع أي ملف نسخ احتياطي يحوي بيانات موكلين أو قضايا حقيقية.
